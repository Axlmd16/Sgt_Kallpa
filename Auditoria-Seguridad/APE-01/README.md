# APE 01 — Análisis y superficie de ataque del proyecto

**Asignatura:** Software Security · Universidad Nacional de Loja
**Proyecto:** [Sgt_Kallpa / Kallpa UNL](https://github.com/Axlmd16/Sgt_Kallpa) · sistema web de gestión deportiva
**Corte:** sesiones del 1, 2, 8 y actividad 1 del 9 de octubre de 2026.

La práctica identifica el proyecto y su superficie de ataque, luego clasifica activos mediante confidencialidad, integridad y disponibilidad (CIA) y formula amenazas preliminares. El análisis se basó en el código local de React, FastAPI y Docker Compose. La guía PDF solicitada no estaba disponible en el entorno.
